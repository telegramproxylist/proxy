Why bother

Why people run Telegram through a proxy

A proxy isn't just for getting around a block. Here's what it actually changes about your connection.

01

Reach Telegram on a restrictive network

Some school, office, and national networks block Telegram's servers outright. An MTProto proxy in particular is built to slip past filtering that targets Telegram's traffic pattern specifically.

02

Keep your IP address off Telegram's servers

Telegram sees the proxy's address instead of yours. Message content is already protected by Telegram's own encryption — a proxy changes what your network address looks like, not what's inside your chats.

03

Route around a slow or congested route

Occasionally a proxy server sits on a better network path to Telegram's infrastructure than your default route does, which can mean fewer dropped connections on an unstable network.

Quick setup

Adding a proxy takes under a minute

The exact screen differs by proxy type, but the shape of it is the same everywhere in the Telegram app.

  1. 01

    Get proxy details

    A SOCKS5 server/port/login, or an MTProto link or server/port/secret.

  2. 02

    Open proxy settings

    Settings → Data and Storage → Proxy in the Telegram app, on desktop or mobile.

  3. 03

    Add and select the type

    Choose SOCKS5 or MTProto and fill in the fields for that type.

  4. 04

    Save and test

    Enable it, then open a chat to confirm messages and media load normally.

Two ways to relay

SOCKS5 and MTProto aren't interchangeable

One is a general-purpose network proxy. The other is a protocol Telegram built specifically for itself. Knowing the difference decides how you should set it up.

SOCKS5 General-purpose proxy

A standard proxy protocol that works at the operating-system or app level. It routes traffic for whatever you point at it — Telegram included — and typically needs a server address, port, and often a username and password.

  • Works across many apps, not just Telegram
  • Supports authentication
  • No obfuscation of its own — traffic pattern is still visible as proxy traffic

MTProto Telegram-native proxy

Built into Telegram's own protocol. It's added through a tg://proxy link or the app's proxy settings, and disguises traffic to look less like a proxy connection — useful where Telegram itself is being blocked.

  • One tap to add from a link
  • Traffic obfuscation built in
  • Only proxies Telegram — other apps are unaffected

FAQ

Common questions about Telegram proxies

What is a Telegram proxy?

A server that sits between your Telegram app and Telegram's own servers, relaying your connection. Telegram supports two kinds — SOCKS5, a general-purpose network proxy, and MTProto, a proxy type built into Telegram's own protocol.

Are Telegram proxies free?

Many SOCKS5 and MTProto proxies for Telegram are shared publicly at no cost, though free servers tend to be slower and less reliable than paid ones since they're shared by many users at once.

Is it safe to use a public Telegram proxy?

Your message content stays protected by Telegram's own transport encryption regardless of the proxy, but a proxy operator can typically see connection metadata — that you're connecting to Telegram, and roughly when. Use proxies from a source you trust and avoid reusing the same third-party proxy for sensitive accounts.

SOCKS5 vs MTProto — which is faster?

Neither protocol is inherently faster; speed depends almost entirely on how loaded the specific server is. MTProto has an edge in places actively blocking Telegram, since it's built to obscure the traffic pattern. SOCKS5 has no such obfuscation.

Does a Telegram proxy hide my IP address from Telegram?

Yes — Telegram's servers see the proxy's IP address rather than yours. The proxy operator, however, can see your real IP address, since your connection to the proxy itself isn't hidden from them.

Can I use a VPN and a Telegram proxy at the same time?

Yes. A VPN routes all of your device's traffic, while a Telegram proxy only affects Telegram. Running both isn't usually necessary, but it doesn't conflict — Telegram's traffic simply passes through the VPN and then the proxy.

Why does my Telegram proxy keep disconnecting?

The most common cause is an overloaded or offline server, especially with free public proxies. Try a different server from an actively maintained list, and remove proxies that no longer respond instead of leaving them saved.
