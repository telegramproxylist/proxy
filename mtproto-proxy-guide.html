What Is an MTProto Proxy? A Complete Guide for Telegram Users

Telegram Proxy Guide·Proxy basics·7 min read

MTProto proxies are the option built directly into Telegram, and they're the reason you can add a working proxy just by tapping a link. Here's what's actually happening when you do that.

MTProto, quickly

MTProto is the protocol Telegram uses to talk to its own servers. An MTProto proxy is a relay that speaks that same protocol, sitting between your Telegram app and Telegram's servers. Because it's built at the protocol level rather than the operating-system level, Telegram can hand you a single link — tg://proxy?server=...&port=...&secret=... — that configures everything automatically.

That's the main practical difference from a general-purpose proxy: nothing to type into a network settings panel, no separate app. You tap the link, Telegram recognizes it, and asks whether to enable the proxy.

Why it exists

In places where Telegram's servers are blocked at the network level — usually through deep packet inspection (DPI) that recognizes and blocks Telegram's traffic pattern — a regular proxy doesn't always help, because the traffic still looks like Telegram traffic to whatever is doing the blocking. MTProto proxies address this by wrapping the connection so it's harder to fingerprint as Telegram specifically, which is why they're the more common recommendation for getting Telegram working somewhere it's being actively restricted.

How to add one

  1. Get a proxy link or set of details — a tg://proxy link, or a server address, port, and secret you enter manually.
  2. Open the link, or go to Settings → Data and Storage → Proxy → Add Proxy → MTProto in the Telegram app.
  3. Enter the server, port, and secret if you're doing it manually.
  4. Save and enable it. Telegram will show a small icon in the interface when a proxy is active.
  5. Test a chat. If messages send normally and media loads, the proxy is working.
Good to know: an MTProto proxy only routes Telegram's own traffic. Your browser, other apps, and the rest of your device's network activity are completely unaffected.

What it protects — and what it doesn't

An MTProto proxy can help you reach Telegram when the app or its servers are being blocked, and it obscures your traffic pattern from basic network-level filtering. What it does not do is replace end-to-end encryption. Regular cloud chats in Telegram are encrypted between your device and Telegram's servers, but not end-to-end — only Secret Chats are. A proxy operator generally can't read your message content, but they can typically see connection metadata: that you're connecting to Telegram, roughly when, and how much data is moving.

That's the reason the source of a proxy matters. A proxy run by someone you don't know is still a third party sitting on the path between you and Telegram, even if it can't read your messages.

Choosing a server

A workable MTProto proxy needs to actually be online, reasonably fast, and current — free public proxy lists change by the hour as servers get overloaded or shut down. Rather than guessing from a static list, it's worth pulling from a source that tests servers regularly.

Where to find one: telegramproxies.com maintains an actively updated list of MTProto and SOCKS5 proxies for Telegram.

Quick troubleshooting

  • Connects then drops: the server is likely overloaded — try a different one from your list.
  • Won't connect at all: double-check the secret was copied in full; a truncated secret is the most common cause.
  • Slow media loading: some proxies handle text fine but struggle with media-heavy traffic — this is normal for free/public servers under load.
